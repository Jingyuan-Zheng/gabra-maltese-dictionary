## Ġabra Maltese Dictionary

An offline Maltese dictionary based on the Ġabra Maltese Open Lexicon, available for MDX-compatible readers and the native macOS Dictionary app.

### Downloads

| Format | File | Contents |
|---|---|---|
| MDX | [GabraMalteseDict_MDX_v1.0.zip](https://github.com/Jingyuan-Zheng/gabra-maltese-dictionary/releases/download/v1.0/GabraMalteseDict_MDX_v1.0.zip) | `Gabra.mdx` and `Gabra.css` |
| macOS | [GabraMalteseDict_v1.0.dmg](https://github.com/Jingyuan-Zheng/gabra-maltese-dictionary/releases/download/v1.0/GabraMalteseDict_v1.0.dmg) | Native `Gabra.dictionary` bundle |

### MDX edition

- 19,831 searchable headwords containing 21,083 source records.
- Definitions, parts of speech, phonetics, and roots where available.
- Editable external CSS that follows the reader's light or dark theme.

Download and extract the MDX ZIP. Keep `Gabra.mdx` and `Gabra.css` together, then import them into an MDX-compatible dictionary reader.

### macOS edition

- 21,083 entries with approximately 4.5 million searchable word forms.
- Definitions, parts of speech, phonetics, and roots where available.
- Integration with the Dictionary app and macOS Look Up.

1. Download and open `GabraMalteseDict_v1.0.dmg`.
2. Drag `Gabra.dictionary` into the `Dictionaries` folder shown in the installer.
3. Open **Dictionary → Settings** and enable **Ġabra Maltese Dictionary**.

The MDX edition searches headwords; the native macOS edition also includes inflected word forms.
