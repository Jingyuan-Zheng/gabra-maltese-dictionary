# Gabra entry-body snapshot

`Body.data` is the entry-body component extracted from the existing Gabra 1.0 macOS dictionary on 2026-10-02. It is included so the MDX can be rebuilt without macOS, the full native bundle, or a fresh upstream download. It is not an independent upstream BSON release, and the original BSON snapshot date is unknown.

- SHA-256: `c0c6b8b73f74661fc26cf91e1a42307e2779795c0e93875861cfdb6173e7757d`
- Source records: 21,083.
- Original source content is unmodified, including the blank headword and comment-like entries.
- Native search-index files are not included; this file alone cannot reproduce the original inflected-form searches.
- Attribution and data license: [Ġabra / MLRS / University of Malta](../../docs/ATTRIBUTION.md).

Apply the documented local correction only when converting. Use `--no-corrections` to preserve an explicit untitled placeholder for the blank headword.
